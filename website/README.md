# trailscope.pro

The Trailscope website: the landing page, planned Cloud pricing with a waitlist, and the documentation. Built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build). Background and choices: decision 065 in [docs/DECISIONS.md](../docs/DECISIONS.md).

```bash
pnpm install                                  # from the repository root
pnpm --filter trailscope-website dev          # http://localhost:4321
pnpm --filter trailscope-website build        # static site in website/dist
```

- **Docs:** edit the Markdown in [`docs/`](../docs), never `src/content/docs/` (generated by `scripts/sync-docs.mjs` on every build). Links between docs become site links, links to other repository files go to GitHub, and a link to a missing page fails the build. The sidebar order is in `astro.config.mjs`.
- **Domain:** `domain.txt` is the only place it is set (canonical URLs, social cards, the contact address, nginx).
- **Screenshots** come from `docs/images`, the same files the README uses.

## Server

The site is static files behind nginx, plus the waitlist endpoint (`waitlist/waitlist.py`, Python standard library, SQLite) as a systemd service on `127.0.0.1:8790`.

```bash
export TRAILSCOPE_SITE_HOST=ubuntu@<server>
website/deploy/setup-server.sh   # once, and after changing deploy/ or waitlist/: nginx site, waitlist service
website/deploy/deploy.sh         # every update: build, upload a new release, switch to it
```

When the domain's A records point at the server, add HTTPS once:

```bash
ssh $TRAILSCOPE_SITE_HOST 'sudo certbot --nginx -d trailscope.pro -d www.trailscope.pro'
```

Each new signup is emailed to `hello@<domain>` (Reply-To set to the person) through Resend when the server has a key; the service reads it from a root-only file:

```bash
ssh $TRAILSCOPE_SITE_HOST 'sudo install -m 600 /dev/null /etc/trailscope-waitlist.env && sudo nano /etc/trailscope-waitlist.env'   # RESEND_API_KEY=re_...
website/deploy/setup-server.sh   # restarts the service with it
```

Waitlist signups, as CSV:

```bash
ssh $TRAILSCOPE_SITE_HOST 'sudo python3 /opt/trailscope-waitlist/waitlist.py export --db /var/lib/trailscope-waitlist/waitlist.db'
```

Delete someone on request: the same command with `delete <email>` instead of `export`.
